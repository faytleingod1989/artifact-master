# **1\. 测试前需准备的真实样本集（由产品/用户提供）**

吸取前期"仅用模拟测试或少数静态图验证，导致实机仍中断"的教训，开发与验收前必须在本地私有测试目录中准备以下真实游戏样本（严禁上传至公开仓库）：

* **多分辨率背包全屏/窗口截图**：覆盖常用分辨率（如 1920×1080、2560×1440、3840×2160）及不同 Windows DPI 缩放（100% / 125% / 150%）。  
* **连续时间序列帧**：包含点击选定、鼠标悬停放大、光圈闪烁及滚轮翻页前后的连续帧，用于离线回放验证，确保不再出现悬停误判。  
* **边界圣遗物样本**：  
  * 包含第 4 条为"（待激活）"的低等级五星圣遗物。  
  * 两件主副词条完全相同的五星圣遗物（且位于相邻格位）。  
  * 背包最底部不足一整行的末页截图，以及五星与四星交界处的截图。  
* **负例样本（必须拒识或拦截）**：包含强光遮挡、非背包界面（如秘境领奖/角色面板）以及伪造异常小数位的负例图。

# **2\. 分阶段可量化验收门槛**

必须同时满足以下所有指标，才算对应阶段交付完成（严禁以"模拟队列通过"替代实机验收）：

## **2.1 功能与稳定性验收（P1 & P2）**

| 验收项 | 验收标准 |
| :---- | :---- |
| **当前页稳定性** | 在用户常用分辨率下，连续 3 次对同一整页完整五星格位（如 32/32）扫描，**0 次因悬停或选中动画误暂停**，无漏格、无错位。 |
| **跨页自动翻页** | 连续跨 5 页以上（150+ 件圣遗物）全自动扫描，翻页重叠行自动去重准确率 100%，到达背包底部或四星边界时准确自动停机。 |
| **相邻同属性保留** | 相邻两件属性完全相同的圣遗物能各自生成独立记录，不被误判为"未切换"或自动删重。 |
| **高置信度自动入库** | 校验通过的正常圣遗物自动入库，**无需人工逐批点确认**；支持点击"撤销本批入库"完整回滚至扫描前状态。 |
| **异常件隔离** | 故意构造的负例或存疑件 **0 件误入库**，全部准确进入"待人工复核"列表且保留原图裁剪。 |

## **2.2 安全与防风控验收**

* **失焦急停**：扫描过程中使用 `Alt+Tab` 或点击其他窗口，工具在当前格位操作前立即停止，**0 次误点其他窗口**。  
* **右键急停**：扫描过程中在游戏内按下鼠标右键，程序在 **≤ 150ms** 内中止后续所有点击与滚轮操作，并等待原生输入线程完全退出后才恢复 `F8`。  
* **绝对不碰敏感按钮**：全程实机录像/日志核查，点击坐标严格限定在圣遗物列表格位安全区内，绝不触碰右侧"锁定""强化""摧毁"或"装备"区域。  
* **拟人化节流核查**：日志中连续点击间隔与点击坐标存在随机波动，无固定毫秒级机械等距连点。

## **2.3 性能验收（P3）**

* **OCR 单件耗时**：启用固定布局 Batch 行识别后，单件圣遗物端到端识别中位耗时 **≤ 250ms**（较现有 \~1.03s 提速 4 倍以上）。  
* **整包吞吐能力**：200 件五星圣遗物全自动扫描 \+ 入库总耗时控制在 **1\~2 分钟以内**，且内存峰值平稳（处理完即释放源图 Blob，不因队列积压导致卡顿或崩溃）。

# **3\. 发布与回退策略**

* **保留旧版与旧启动器**：新候选包实机验收全部通过前，严格保留旧版 EXE、用户本地库存数据库与历史截图，不覆盖默认启动入口。  
* **功能开关降级**：界面保留 `F8` 手动连拍与传统"人工确认入库"开关；如遇到极端分辨率或游戏版本 UI 大改，用户可一键切回 `F8` 模式继续正常使用，不影响既有库存与配装计算功能。

# **1\. 界面布局与交互原型说明**

在不重写现有仓库管理、121 角色配装和 \+20 潜力计算界面的前提下，对"采集录入"面板做轻量化改造：

## **1.1 扫描模式入口区（采集面板顶部）**

保留三个平级选项卡/切换入口，让用户自由选择：

* **一键全自动扫描（推荐 / 新增默认高亮）**：自动逐格点击、自动滚轮翻页、高置信度自动入库。  
* **F8 手动连拍（保留兜底）**：按一下 `F8` 截一件，适合日常刚刷完副本补充 1\~5 件新胚子。  
* **批量图片 / UID 展柜导入（保留不变）**：拖入截图或通过 Enka.Network 查询公开 UID。

## **1.2 全自动扫描配置项（折叠或紧凑一行展示）**

在"一键全自动扫描"面板下提供 3 个直观开关：

1. `[✓] 自动向下翻页`（默认开启；关闭则退化为仅扫当前页）  
2. `[✓] 校验通过自动入库`（默认开启；关闭则全部进待确认列表）  
3. `[ ] 遇到 +0 圣遗物自动停止`（默认关闭；开启后适合只扫已强化胚子）

## **1.3 扫描过程中的实时状态栏**

当用户点击"开始全自动扫描"并切回游戏后，工具主界面（及可选的小型置顶状态条）实时更新以下文案：

* **准备中**：`请切回《原神》圣遗物背包页面并保持静止，按下鼠标右键可随时急停。`  
* **扫描中**：`正在全自动扫描 · 已截图 64 件 | 已自动入库 58 件 | 待人工复核 2 件（右键立即停止）`  
  \|---\|**已暂停（失焦）**：`检测到游戏离开前台，已安全暂停。请切回游戏后点击"继续"或直接结束。`

## **1.4 扫描结束汇总卡片（收尾与一键后悔药）**

扫描结束（进入 `completed` 状态）并切回工具后，顶部展示一张清晰的汇总卡片：

* **主文案**：`本次全自动扫描完成：共采集 142 件，已自动入库 139 件，另有 3 件需要你核对。`  
* **操作按钮**：  
  * `[查看并处理 3 件待核对]`（主按钮：直接定位到那几件异常/疑似重复的圣遗物）  
  * `[撤销本次自动入库的 139 件]`（次级警示按钮：按批次 ID 一键回滚本次自动入库的所有记录，恢复到扫描前库存状态，避免误扫污染仓库）

# **2\. 防回归红线（开发绝对不能改坏的基线）**

为防止开发过程中为了追求"全自动"而破坏原有核心功能或安全性，以下 6 条红线必须写入开发检查清单：

| 红线编号 | 红线要求 | 说明 |
| :---- | :---- | :---- |
| **R1** | **数值严苛校验绝不放宽** | 保持现有的五星圣遗物真实强化档位校验，绝不四舍五入篡改异常识别值；`6.5%` 与 `6.59%` 必须严格区分，不能靠猜数值提高"自动入库率"。 |
| **R2** | **低等级"待激活"词条完整保留** | 必须继续准确识别并独立存储第四条"（待激活）"副词条，且不将其计入当前已生效评分。 |
| **R3** | **真实同属性圣遗物不误删重** | 两件属性完全相同的圣遗物必须可以同时保留在仓库中；自动入库时仅标记"疑似重复"并转入待核对，禁止静默丢弃。 |
| **R4** | **原有录入入口与数据存档完全兼容** | 不得破坏 `F8` 手动连拍、批量截图、UID 导入与手动录入；IndexedDB 本地仓库、回收站、强化队列与 JSON 备份格式保持向后兼容。 |
| **R5** | **零侵入与权限隔离底线** | 严禁读取游戏内存、严禁进程注入、严禁自动提权、严禁点击游戏内锁定/强化/装备按钮。 |
| **R6** | **公开构建与本地个人版隔离** | 继续遵守 [README.md](https://drive.google.com/file/d/1HVfWplbuc7Tu_G4Si6oZOETSvi-K6WA9/view?usp=drivesdk) 中的构建门禁，确保公开构建不包含第三方版权美术原图。 |

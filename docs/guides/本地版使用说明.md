# 圣遗物管理大师 · 本地版使用说明

## 启动与版本隔离

优先双击项目根目录的 `启动圣遗物管理大师.vbs`，无需安装 Node.js 或打开命令行。它会启动下方的 Windows 便携程序：

`apps/web/release-local/ArtifactMaster-0.1.0-capture-potential-20261018-local.exe`

这是 Windows x64 个人便携包。入口只认这个文件；缺包会明确报错，不会自动打开公开版或旧版。按用户要求，本轮验证通过后清理旧发布 EXE，只保留最新版便携包；旧包移入回收站。不要把公开包当作个人包的替代品。

清理状态：此前的 `pending-sound` 和 `characters-20261017` 两份便携包已移入 Windows 回收站。本轮曾检测到旧 `all-characters-20261018` 进程运行，先保留；最终复查时进程已退出，经路径、哈希和独占文件锁核对后，旧包也已移入回收站，发布目录只保留 `capture-potential-20261018` 新版便携包。没有强行关闭程序，用户库存和截图均未删除。根目录入口只启动新版，不要同时运行两个版本编辑同一库存。

## 连续截图与角色潜力（2026-10-18）

实时录入已经分离截图和OCR：按F8取得一张独立画面，听到“截图完成”的短音后即可切下一件，不必等识别完成。后台按截图顺序识别；上扬音表示识别成功并进入待确认，不表示入库。两种声音分别可关闭，旧版静音偏好会同时应用到新声音。

一批最多20个未入库任务，包含正在截图、排队、识别、失败和待确认。编码源图单张16MiB、合计128MiB；大尺寸画面可能先触发字节限制，达到限制会明确拒绝新图并保留旧图，不会覆盖。截图本身尚未完成时再次按F8会提示未接收，不能在听到捕获音前就切换画面。

任务卡可切换预览，查看对应原文和取帧、排队、OCR等耗时。识别失败可“重新识别此图”，只使用保存的原图；想另拍当前游戏画面则用上方“采集当前详情”或F8，新图是新任务。已取消旧任务的“自动补拍当前画面”，防止切到下一件后串图。

“停止采集”现在暂停新截图、释放F8，但继续处理已保存图片；“启动实时采集”可恢复同一来源。“停止并核对批次”会排空OCR后打开成功草稿；失败图保留，返回任务列表可继续处理。关闭并丢弃会确认所有未入库任务。换来源前先处理本批；窗口丢失不会转成整个屏幕，已有图片仍能识别。

库存详情向下滚动可看到“角色适配与潜力”。角色下拉分为该套装推荐和其他角色，可搜索全部121位角色并切换玩法。默认跟随配装页，手动改选仅用于单件比较，不改变全局角色或库存；切换藏品仍保留比较角色，点击“跟随配装角色”恢复。上方原“规则初评”仍对应全局配装角色，下面“当前适配分”及潜力才对应本区域选中的比较角色。

当前分只计生效词条；+20理论范围使用真实五星标准档位、已发生/剩余强化节点及所有合法舍入历史。三词条首次强化要先激活第四条；已知待激活值固定，未知第四条考虑合法类型，范围可能更宽。合法满级件范围收敛当前分；无法组成合法历史的旧数据显示“需核实”，原数据不会被改写。

评分是启发式角色单件适配，不是实战伤害。区间是理论极值，不是期望、概率或强化保证；不默认凑齐套装。武器、外部暴率/充能及玩法条件可展开查看。潜力在离线后台计算，切换角色会取消过期任务，避免旧结果闪回。

本轮验收与限制见 `docs/连续录入与角色潜力-20261018-验收.md`。

本版修正了 Windows 短临时目录（如 `ADMINI~1`）被误判为非法页面、导致窗口列表空白及 F8 无法注册的问题。更新后请先保存并退出仍在运行的旧版，再通过根目录启动器打开新版；已经打开的旧版不会自动变成新版。该目录问题无需修改运行权限；详情裁剪仍由程序自动分析。若游戏以管理员权限运行，游戏内 F8 的权限问题请按下一段处理。

窗口模式使用主进程的本地窗口快照取帧，每次只返回你已选择并在本次来源列表中核实过的窗口，不依赖原先启动失败的视频源，也不会自动退回整屏。原神与工具运行权限不同且游戏里的 F8 不送达时，可以自行决定仅对这次运行使用管理员权限；程序不自动提权。截图仍只在内存中处理。窗口关闭、来源变化或黑屏时拒绝识别，需要重新选择来源。

个人包包含已有的个人圣遗物原图；公开包位于 `apps/web/release`，不得包含这些个人原图。构建素材隔离不表示可以删除用户数据：不要删除或覆盖原用户数据目录，升级前先导出 JSON 备份。自定义角色头像只保存于当前设备，不会自动加入发布包。

## 全部角色与分类（2026-10-18）

角色档案现已扩展至当前7.1所有已实装角色，共121位（含四星和联动角色，旅行者不重复计数）。左侧可按全部、火、水、风、雷、草、冰、岩筛选，保留搜索。默认“五星优先 · 新角色在前”；改为“老角色在前”时仍维持五星在四星之前。同星级按首次实装先后，不按复刻时间排序。

旅行者可切换七种已实装元素；从某个元素分类点击旅行者会打开对应元素玩法。每个元素分类里都计入旅行者，所以分类数量之和会比角色总数多6。角色头像保持原始比例，所有新档案均带建议套装、主词条、属性权重、充能条件及资料来源，实际参与配装推荐。

详见 `docs/全部角色档案与分类-20261018.md`。评分仍是工具规则，不是精确伤害模拟；部分高命、武器、套装与队伍条件需要自行确认。

## 角色档案与配装基础（2026-10-17）

“角色配装”新增6.0至7.1已实装角色的完整档案；含四星角色，共19位新角色，保留原有4位，总计23位。头像采用原始游戏图并保持比例，可按名称、元素、版本或定位搜索。

每位角色有建议主词条、首选/替代/过渡五星套装、相对属性权重、充能循环假设、机制注意事项与资料链接。不同玩法可切换，例如雷电将军的站场爆发/超绽放、法尔伽的转换元素、莉奈娅的按需/每轮治疗、阿罗夏的单雷/双雷、沃雅妮莎的攻击/生命倍率队。

点击“查看该角色推荐”会按所选玩法在实际库存里尝试4件或2+2加散件，并显示真实件数。缺少套装或主词条会明确提示，不会造出不存在的藏品。也可选“不限套装”。仓库详情和强化队列沿用同一玩法规则。

权重按约一次有效词条提升归一化，不直接用大生命整数压过双暴；满暴后不继续加分，超过参考充能上限保留少量权重。武器/队友的额外暴率、充能可在“武器、队友与条件设置”调整。有条件的套装暴击默认不计入，只有手动确认且实际凑齐4件才估算。档案中写明的被动上限不代表所有后续属性收益归零。

规则总分不是伤害，也不是最优配装证明；充能需按自己队伍实测。词条异常或与等级、部位冲突的旧记录保留在仓库，但排除候选并提示核实，不自动修正。档案来源和评分边界见 `docs/角色档案与配装规则-20261017.md`。本次不代表新增两套圣遗物图标缺图问题已解决。

## 实时录入（Windows 桌面版）

2026-10-17 待激活与提示音版：低等级圣遗物显示的第四条“待激活”副词条正常识别，单独保存、显示和编辑，不计入当前生效属性或评分；升级后请重新采集核实，不自动推断激活结果。缺失右括号的明确“待激活”尾注也能识别，异常数字仍拒绝，不会四舍五入修正。

“成功识别提示音”默认开启，只有完整识别并成功加入待确认后才播放一次短音。自动跳过、失败、补采中或停止后的迟到结果不响；音效不表示已经入库。可取消勾选静音，选择会在本机记住。播放不抢焦点、不联网；音频设备故障不影响草稿保留。已验证真实浏览器失焦播放及实际合成波形；系统静音、音频输出设备及原神全屏前台实际听感仍需按本机设置检查。

2026-10-17 新引擎版：Windows 默认使用本次实测较快的 PP-OCRv5 mobile 检测器 + server 中文识别模型，通过本机 CPU 运行。模型和独立运行组件均包含在便携包内，无需安装 Python；不会在运行时下载模型或上传图片。首次启动识别会加载模型，空闲时复用已加载的进程，以减少后续启动开销。模型或组件缺失会明确报错，不会偷偷退回旧引擎；浏览器预览不具备本机组件，仍用旧的离线 Tesseract 流程。

新引擎先检测文字框，再识别原色详情；旁边的特效不直接导致整行拒绝，长条过曝穿过实际文字框时仍会拒绝。词条项目符号可能读成问号/冒号，程序只清理这种前导装饰，不替换数字。错误精度如 6.59% 仍明确拒绝，不会改成 6.5%。OCR 原文包含实际引擎名，可核实确实运行的是 PP-OCRv5-server。

用户新图与原有 11 张原图已通过新引擎逐字段校验 12/12；这是固定样本验证，不代表所有画面都能正确识别。新图在本机“收到完整截图后自动定位并识别”约 1.2 秒，不含窗口取帧和首次模型加载；持续处理的耗时可能因系统负载变化。包内运行组件约 317 MB（未压缩），因此新包比旧包大，空闲热模型也会占用一定内存。强特效遮住文字时仍需重新采集。

先进入“圣遗物仓库”页。录入与“仓库备份”入口均在该页，不再散布于长页面中。

1. 在游戏中打开一件圣遗物的详情页。
2. 在仓库页点击“实时录入”，刷新并选择可见的游戏窗口，点击“启动实时采集”。程序立即采集一次，并自动分析右侧详情区域；不需要框选或输入坐标。预览应只显示详情，不是整张游戏画面。
3. 看到“F8 已启用”后切回游戏，切换圣遗物后按 `F8`，也可点击“采集当前详情”。界面显示收到 F8 的次数：若一直为 0，按键未送达工具，可检查快捷键冲突或游戏与工具的运行权限；程序不会自动提权。“自动辅助检测”默认关闭，主动勾选后才定时识别，相同详情不重复加入；显式 F8 或按钮采集仍允许同词条的另一件实物。
4. 最多保留 20 件待确认草稿。点击“停止并核对批次”，成功识别的信息已自动填好，核对摘要后点击“确认并入库”；只有需要改动时才点击“修改识别信息”。疑似重复仍须明确选择新增、更新或跳过。

识别缺字段或数值校验不通过时会提示重试，不打开空白表单让你重填，也不会入库。保持圣遗物名称、主副词条和绿色套装名称完整可见，重新按 F8 或点击采集即可。自动定位目前针对中文横屏圣遗物详情；不支持的画面会明确拒绝。

2026-10-17 续修：先规范化已知词条名称，再使用真实识别的数字结果；`6.5%` 不会因为名称错字、尾部装饰符而被拒绝，但不会把 `6.54%` 四舍五入放行。异常提示显示实际解析值，失败时也能展开“查看本次 OCR 原文与耗时”，查看捕获、定位、预处理、OCR、解析和总耗时。首轮另列启动耗时，补采单独计时。

蓝底详情按左侧词条文字独立分行，避免右侧亮光将多行合并。检测到长条高亮特效遮挡时，实时采集最多补采一次：需先识别出套装、部位、等级、主词条和至少两条未遮挡的合法副词条，且补采内容与这些信息一致。第二帧作为完整独立结果，不拼接两帧；信息不足、冲突或仍被遮挡时明确失败，不自动入库。可见信息相同也不保证是同一件实物，补采成功会有核对提示。截图导入不会获取新帧。

2026-10-15 更新区分蓝底详情和浅色卡片，自动分析深浅文字与左侧主词条位置；修正数字边距造成的 311 → 31 误读，并减少已正确识别词条的重复复核。本地 11 张蓝底原始截图（含用户补充的 +17 生之花）在自动定位下逐字段正确 11/11，套装、部位、等级、主副词条均作比对；另有浅色卡片程序预览的低分辨率回放与自动定位回放测试。回放不是原始 4K 卡片验收，也不表示所有游戏画面都能正确识别，确认前仍需核对。

同一批 11 张原图的识别阶段总耗时由约 47.6 秒降至 24.3 秒（平均约 4.3 → 2.2 秒，不含初始化和窗口取帧）。原生窗口取帧仍可能耗时约 4～6 秒；这不是按 F8 到入库的总耗时承诺。程序仍不自动入库，也不会通过成长表编造缺失数字。

“停止采集”会注销 F8；“关闭并丢弃未入库草稿”不会保存未确认内容。确认页可查看本次预览与 OCR 原文。

实时录入只在 Windows 桌面程序中可用，采用本地屏幕采集与本地 OCR；不读取游戏内存、网络、账号或 UID，不注入游戏，也不会模拟任何游戏操作。截图帧只在内存中用于本次识别，不会上传或落盘。请自行评估并遵守游戏当前规则，程序不承诺账号风险为零。

## 批量截图识别（1～20 张）

1. 在顶部“更多录入”选择“选择多张截图”；单张可选“识别截图”。
2. 一次选择 1～20 张 PNG、JPG 或 WebP 格式的圣遗物详情截图（单张不超过 16 MB）。
3. 程序逐张自动分析并裁剪详情区域，然后在本机识别；无需框选。失败时可“重新识别当前截图”，不会自动猜值或创建空白待核对表单。
4. 完成后查看已填好的识别摘要，需要修改时再展开编辑，核对处理方式后点击“确认并入库”。也可点击“仅核对已完成 … 件”。

批量识别不会静默入库，也不会将游戏截图保存到仓库；确认页保留本次本地来源预览，方便核对。关闭确认页前，请先保存需要的条目。

## 手动录入和疑似重复

顶部“手动录入”可新增草稿。确认页会显示疑似重复的本地编号并默认“跳过”；同词条不等于同一件实物。“新增一件（不覆盖）”保留两件，“更新已有记录”必须明确选择本地记录。保存失败时草稿保留，修正问题后重试，只有确认保存成功才结束核对。

## UID 展柜导入

顶部点击“UID 展柜导入”，输入公开展柜 UID 后主动点击“查询公开展柜”。使用第三方 Enka 服务，只读取公开角色展柜，不是整个背包；无需登录、密码、Cookie 或 Token，不会上传本地仓库。浏览器预览不支持该查询。

勾选有效五星条目后点击“核对所选圣遗物”，再人工确认入库。疑似重复默认不选；未知套装、名称或部位会提示，不能静默入库。冷却结束后需手动刷新，不自动重复查询。“仅在此设备记住 UID”默认不勾选，可以取消并删除已记住的 UID。新记录锁定状态为工具本地默认值，不代表游戏内锁定状态。查询失败不会改变仓库。

## 数据与素材

- 圣遗物、强化队列和回收站保存在本机；不会读取游戏目录、游戏进程、登录账号、Cookie 或 Token。UID 查询仅使用你主动输入的公开 UID。
- 在独立的“本地素材”页可导入你自行提供或获得授权的角色头像，不提供单件圣遗物图标上传。
- 图片仅存于本机浏览器数据中，不会上传，也不会被打包进程序。
- 在顶部“仓库备份”使用“导出 JSON”，新版 v2 备份包含库存、回收站、强化队列和自定义角色头像；换电脑后用“导入 JSON”恢复。旧版不含队列的备份恢复时会清空队列，不会沿用原仓库的旧编号。替换仓库、升级或换电脑前先导出备份并妥善保管。
- 普通自动保存失败时，界面中的修改仍保留；点击“重试保存当前修改”保存当前内容，不要通过重新读取来覆盖未保存修改。失败时也可以导出当前数据备份，保存成功后再关闭程序。

## 强化队列

队列最多五件，五件全部可见。每件的“移出队列”按钮只移出队列，“清空队列”只清空队列，都不会删除库存。重复加入不会新增重复项；队列满时会明确提示未加入的数量，可先移出一件再加入。

## 七个独立页面

顶部导航会切换页面内容，不再滚动到同一张长页面。窄屏窗口使用底部横向导航，七个入口均可切换。

- 圣遗物仓库：录入、筛选、列表/图标、详情、多选、对比及 JSON 备份。
- 角色配装：选角色、看工具规则偏好和五部位候选概览；不是游戏内当前装备。
- 推荐方案：逐部位候选、规则评分及依据；不会自动修改装备，也不代表实战最优配装。
- 强化队列：查看最多五件藏品，可返回库存查看。
- 数据图鉴：独立于个人库存的已核实五星目录、五部位名称、主词条成长值和副词条校验范围。只读本地快照；套装效果暂未收录，不会自动联网或编造缺少的资料。
- 本地素材：游戏原版头像与本机自定义头像。
- 回收站：恢复藏品或明确永久清空；没有自动 30 天删除机制。

切页不会清空仓库筛选、排序、视图、多选、详情或对比；角色选择由相关页面共享。重新启动默认进入仓库。成功恢复整库备份会清除旧库的详情、多选和对比引用，取消或拒绝导入不会重置它们。

从推荐或队列查看某件藏品时，若它被仓库筛选或角色范围隐藏，会明确提示；只有你点击“清除筛选并查看”才会清除这些限制。全部图片保持原比例。图鉴目录目前为 46 套 / 230 个名称，个人包原图有 44 套 / 220 张，剩余 10 张明确显示待补；这不是已补齐的承诺。

## 推荐的录入顺序

1. 程序自带 10 个角色头像，可直接使用；“本地素材”中的自定义头像导入是可选操作。
2. 通过“手动录入”、“实时录入”、“更多录入”中的截图入口或“UID 展柜导入”新增圣遗物；所有来源都必须确认后入库。
3. 选择角色，查看当前库存的规则初评与强化建议。推荐为逐部位候选，不代表完整套装、循环或实战最优配装。
4. 将想强化的条目加入“强化队列”。
5. 定期导出 JSON 备份。

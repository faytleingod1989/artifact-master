# 原神圣遗物详情页 OCR 分区识别设计

## 目标

对原神横屏圣遗物详情截图，在本地自动提取并预填：名称、套装、部位、等级、主词条和最多四条副词条。识别不能确定的字段保持为空或默认值，由用户在确认表单中修正；不会基于猜测写入仓库。

同时校正当前五星圣遗物目录中的全部简体中文套装名，并将历史错误名作为仅输入兼容的别名保留，避免既有本地数据与 OCR 文本失配。

## 范围与边界

- 输入为用户选择的本地 PNG、JPG 或 WebP 截图；不上传到网络。
- 优先支持 16:9 横屏原神详情页；竖屏或无法匹配布局的图保留现有整图识别降级路径。
- 继续使用现有 Tesseract 中文/英文离线能力，不新增在线服务或大型本地模型。
- 结果仍进入现有“确认并入库”流程，OCR 不直接创建圣遗物。
- 中文名称以可复现的游戏数据 TextMap 为主来源；争议项需用当前中文资料页复核。界面和后续存储统一使用更正后的正式名称。

## 处理流程

1. 读取截图尺寸；当宽高比大于等于 1.3 时，按右侧详情栏的相对区域建立三个裁剪区：
   - 标题区：名称与部位。
   - 属性区：等级、主词条与副词条。
   - 套装区：套装名；忽略长篇套装效果描述。
2. 每一区域分别以 Canvas 放大、灰度化、对比度增强和轻度二值化处理；源图只在内存中使用。
3. 使用单个本地 OCR worker 顺序识别三个区域，并针对区域设置适合短行/稀疏文本的页面分割模式。
4. 合并三区 OCR 文本，保留清晰的区域标签供用户核对。
5. 由纯函数解析已审计目录内的正式套装名和历史别名、五种部位、`+0` 至 `+20` 等级、有效词条名和数值格式；别名命中时保存正式名称。
6. 只有解析结果命中确定规则时才预填对应输入框；套装仅在完整目录名称命中时选择，副词条仅保留最多四条。

## 失败与降级

- Canvas 不可用、裁剪失败或非横屏截图：回退为当前整图 OCR，保留人工确认。
- 区域 OCR 失败：显示已成功区域的原文与结果，不阻塞表单。
- 未命中任何有效字段：不自动选择套装或填入伪造数值，并提示用户核对。

## 测试

- 图像区域计算：16:9 截图生成互不越界的标题、属性、套装区域；非横屏不裁剪。
- 名称审计：每个当前五星目录项与可复现中文 TextMap 名称一致；“柔灯挽歌”作为旧名解析为正式名称“纺月的夜歌”。
- 解析器：给定分区 OCR 文本，正确提取截图中的“司信者的圣冕、理之冠、+20、暴击伤害 62.2%、元素精通 +40、防御力 +16、暴击率 +3.9%、元素充能效率 +22.7%、纺月的夜歌”。
- 噪声回归：左侧背包与长套装说明中的文本不会覆盖已匹配的字段。
- 现有 OCR 确认入库与实时截图流程继续通过。

## 验收标准

- 对用户提供的 16:9 示例截图，表单自动预填正确部位、等级、主词条、四条副词条和套装；名称在 OCR 可读时预填，否则空着等待用户确认。
- OCR 原文按照区域展示，且不再以整张截图的混杂文本作为唯一结果。
- 所有处理离线完成，截图不被保存到仓库或上传。

## 修复行为

renderer 继续自动定位原色详情，不要求用户框选；Windows 通过受限 preload 会话调用主进程固定本地 helper，采用有界 JSON 行协议。没有任意文件读取、shell、远程 OCR 或模型运行时下载接口。固定模型分别验证 SHA256；helper 禁止 Python socket 连接，但这不是 OS 级网络沙箱承诺。

文字检测框用于分组主词条名称与右侧数字。只清理行首误认的项目符号（包括问号、冒号），不改数字；6.59% 不会被舍入成 6.5%。保留原文并在其中显示实际引擎名 `PP-OCRv5-server`。实际文字框旁边的亮光不直接让整行失败，长条过曝穿过文字框时仍拒绝。已有确认入库、重复处理、20 件上限与停止/取消行为沿用。

桌面缺少组件会明确失败，不静默回退旧引擎。浏览器预览没有本地 helper，保留原来的离线 Tesseract。这是 Windows 单机使用范围内的选择，不是浏览器版也换成了 V5。

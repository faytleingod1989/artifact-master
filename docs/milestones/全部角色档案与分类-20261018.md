# 全部角色档案与左侧分类

范围核对：2026-10-18，当前7.1已正式实装角色。现有23位保留，新增98位，共121个角色档案身份；包含四星、五星和埃洛伊，旅行者合并为一个入口，可切换七种已实装元素。UGC奇偶、试用角色和旅行者重复实体不重复收入。圣遗物建议仍只使用五星套装。

## 页面操作与排序

左侧提供“全部 / 火 / 水 / 风 / 雷 / 草 / 冰 / 岩”和数量、名称搜索、新旧顺序切换。始终五星在前、四星在后；在同星级里，默认首次实装较新的在前，可改为老角色在前。新旧不按最近复刻时间计算，同版本也区分前后期。同日角色用名称稳定排序，不改变当前所选角色或自定义头像键。

旅行者在全部列表里只计一位，在每个已开放元素分类里都可找到，因此七种元素分类数量相加会比总数多6。点击某个元素分类下的旅行者会直接打开该元素玩法，仍可在“配装玩法”里切换元素。

## 新增档案与推荐

- 1.x：33位新增角色，58种条件玩法；2.x～3.x：33位新增角色，48种条件玩法；4.x～5.x及旅行者：32个新增档案。每位均含五星建议套装、合法主词条、相对副词条权重、循环假设、注意事项和直接原作者资料链接。
- 盾辅、治疗、普通扩散、激化、超绽放、烈绽放和直伤分开评价，不把所有角色统一按攻击双暴评分。零命是基础假设；六命诺艾尔、一命冰旅行者等方案明确标明命座，不冒充零命收益。
- 玛薇卡、丝柯克等特殊能量机制不追普通充能；心海的固有暴击率降低也计入估算。回能武器、普通非回能武器和西风暴击条件按每种玩法列出。
- 所选玩法实际参与仓库候选、推荐页、库存详情和强化队列。优先满足建议主词条与真实4件/2+2组合，缺少库存时提示，不生成虚假藏品。待激活词条仍不当作当前生效属性。
- 暴击溢出和参考充能处理沿用已有规则。条件暴击不全部自动视为生效；冰套、双冰共鸣、特定天赋等请按档案说明在外部属性中确认。权重是工具启发式，不是官方标准、精确DPS或全队最优证明。

## 身份、顺序与来源

121位名单与身份快照：`apps/web/src/characters/roster.snapshot.json`。119个合并后游戏身份来自固定游戏表提交`26df1dfbdf05a82bbb1d97506859f3e1c40718d8`中的AvatarExcel、AvatarCodex、突破属性和中文MediumCHS文本；另两位7.1角色保留此前官方Wiki核对身份。

顺序先比较首发版本，再比较同版本AvatarCodex初始开放顺序。原表时间戳只作为顺序键，不作为对用户展示的准确时区日历；可莉的首发顺序明确改为2020-10-20，以免原表同开服时间造成误排。突破暴率和充能从对应角色90级突破表取得，不借用别的角色。

配装与循环由三个独立资料任务逐角色查阅原作者KQM指南，直接链接保存在每个档案中，包括完整指南和快速指南，不盲目拼接不存在的地址。代表性来源：[班尼特](https://keqingmains.com/q/bennett-quickguide/)、[心海](https://keqingmains.com/q/kokomi-quickguide/)、[夜兰](https://keqingmains.com/q/yelan-quickguide/)、[闲云](https://keqingmains.com/q/xianyun-quickguide/)、[玛薇卡](https://keqingmains.com/q/mavuika-quickguide/)、[丝柯克](https://keqingmains.com/q/skirk-quickguide/)。数值权重由本工具整理，不宣称得到指南作者认证。

冰旅行者的正式服七元素依据包括游戏开放技能数据、7.0更新后的原作者资料及[星超导配装图](https://keqingmains.com/i/cryo-traveler-stellar-conduct/)、[星扩散配装图](https://keqingmains.com/i/cryo-traveler-stellar-swirl/)。资料图中的一命与星锋剑条件在程序里单列；零命默认不照抄该充能结论。

121张角色头像均为原始PNG、256×256、等比显示，不裁拉变形。完整URL、身份、尺寸、字节数与SHA256见`docs/artifacts/character-portraits.source.json`。新增98张从核对过的游戏iconName取得；原有官方Wiki两张不虚构游戏ID。

游戏原图仍只进入个人本地包，公开构建隔离；自定义头像优先且只在本机保存。升级不改库存、回收站、强化队列或备份格式。已有炉火融炼之心、血红之证两套圣遗物图标的缺图问题不在本次角色补全内，不能据此宣称所有圣遗物素材齐全。

# 角色档案与配装规则

核对日期：2026-10-17。范围：6.0至当前7.1正式实装的19位新角色（含四星），加上原有雷电将军、那维莱特、芙宁娜、阿蕾奇诺，共23位。圣遗物推荐仍仅使用五星套装。未实装角色、UGC人偶及主角形态不另作新角色收入。

## 档案和使用

在“角色配装”搜索角色，可查看元素、武器、星级、首发版本、玩法、建议主词条、首选/替代/过渡套装、循环假设与来源。选择玩法后，“推荐方案”、仓库详情与强化队列沿用同一套规则；切换角色时恢复该角色默认玩法与条件，避免继承上个角色的武器词条。

## 推荐边界

- 权重是本工具可解释的启发式，不是官方推荐数值、伤害模拟或精确提升百分比。默认零命，武器和队友条件见各档案。不能把所有队伍的充能要求写成单个通用阈值。
- 按“约一次有效词条提升”归一化：暴率3.3、暴伤6.6、攻/生命%5、防御%6.2、精通20、充能5.5、攻击整数17、生命整数254、防御整数20。此表仅是评分尺度，不是合法强化档位表；不拿它改写OCR结果。
- 建议主词条优先于错主词条。按建议套装顺序尝试实际4件或2+2加散件；无可用完整方案时明确标为散件，不宣称套装已生效。“不限套装”可直接比较散件。搜索有界，并非穷举全队最优。
- 暴率按基础5%、90级突破、声明武器/手动外部属性及所选圣遗物估算；超过100%的部分不加分。只有实际凑齐对应4件且主动确认条件满足时，计入穹境30%、风起20%、逐影36%、黑曜40%、幻灭/血红16%。双冰、队友与其他天赋条件不自动假定。
- 充能按基础100%、突破、声明武器、实际二件套及主副词条估算。金珀回能不是面板充能，不能直接加百分比。超过所选参考上限保留15%相对权重；仍须实战检验循环。
- 待激活副词条不参与当前属性和评分。不修改库存。主词条与部位/等级不符、明显越界、重复或与主词条冲突等异常记录保留供查看，但排除候选并提示核实，不通过猜测数值修复。
- 推荐显示的是库存候选，不是游戏当前装备。角色/武器等级、敌人、命座、队友覆盖与手法会改变实际收益。

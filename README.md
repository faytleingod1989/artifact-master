# 圣遗物管理大师 · 星穹典藏 (Artifact Master)

一款面向《原神》玩家的 **Windows 本地离线圣遗物管理、实时 OCR 采集与角色配装潜力评估工具**。

所有库存数据、识别模型与配装计算均在**本机离线运行**，不读取游戏内存、不注入进程、不修改游戏存档、不上传任何个人数据。

---

## 核心功能

### 1. 多方式圣遗物录入
- **当前页自动扫描（仅当前页 · 不自动翻页）**：
  - 自动识别背包当前页最多 32 个五星圣遗物格位（`4×8` / `4×6` 等布局），建立页面锚点后逐格点击并截取详情。
  - **严格安全边界**：内置悬停清除、选中框/缩放姿态补偿、跨格详情稳定校验与页面锚点比对；**绝不自动翻页、绝不修改游戏内锁定/装备状态、绝不自动静默入库**。失焦或按下鼠标右键立即紧急停止。
- **F8 实时单件连续截图**：
  - 截图与 OCR 异步解耦：游戏内按 `F8` 听到快门提示音即可切下一件，后台队列（单批最多 20 件）按序完成识别。
- **批量截图导入（1～20 张）**：
  - 支持拖入或选择 PNG / JPG / WebP 圣遗物截图，自动定位详情区域并批量识别。
- **公开 UID 展柜导入**：
  - 通过 Enka.Network 查询玩家公开角色展柜中的五星圣遗物，核对后手动确认入库（无需登录账号或 Cookie）。
- **手动录入与重复比对**：
  - 支持手动创建草稿，入库前自动检测疑似重复藏品并提供“跳过 / 新增一件 / 更新已有记录”三种显式决策。

### 2. 双引擎离线 OCR 识别
- **Windows 原生 PP-OCRv5 引擎（默认）**：
  - 采用 `PP-OCRv5 mobile` 检测 + `PP-OCRv5 server` 中文识别模型，针对圣遗物标题、主词条、副词条、等级与套装名进行专项行切分与精准校验。
- **WebAssembly 离线 Tesseract.js 回退**：
  - 浏览器开发预览模式下自动使用固定的 `4.0.0_best_int` 离线语言包。
- **严苛数值防伪校验**：
  - 结合五星圣遗物真实强化档位校验词条合法性，支持低等级圣遗物第四条“（待激活）”副词条识别与独立存储，绝不四舍五入篡改异常识别值。

### 3. 121 位全角色档案与单件潜力计算
- **全角色配装推荐**：
  - 内置至 7.1 版本共 **121 位角色**（含旅行者七元素流派与四星角色）的推荐套装、主词条、属性归一化权重与充能要求。
  - 基于真实库存组合 `4 件套`、`2+2` 或散件方案，明确提示缺失部位。
- **+20 强化潜力区间（Web Worker 后台计算）**：
  - 基于五星圣遗物真实四档强化数值与合法舍入历史，计算任意未满级圣遗物在目标角色玩法下的**当前适配分**与 **+20 理论最低/最高潜力区间**。
- **强化队列与回收站**：
  - 支持将高潜力胚子加入强化队列（最多 5 件）对比跟踪；删除操作先进入回收站，支持一键还原与全量 JSON 备份导入/导出。

## 快速开始

### 环境要求
- **操作系统**：Windows 10 / 11 (x64)
- **开发环境**：Node.js `>= 20`、npm

### 1. 安装依赖

```bash
cd apps/web
npm install
```

### 2. 开发预览与单元测试

```bash
cd apps/web

# 启动 Vite 前端开发服务器
npm run dev

# 运行前端单元测试 (Vitest)
npm test

# 运行 Electron 主进程与原生扫描器回归测试
npm run test:electron

# 运行代码静态检查 (Oxlint)
npm run lint
```

### 3. 构建说明（公开构建 vs 个人本地构建）

本项目严格区分**公开构建（Public）**与**个人本地构建（Personal Local）**：
- **公开仓库与公开构建（`npm run build`）**：使用内置占位图标，不包含任何第三方原版圣遗物或角色立绘图片，并通过 `scripts/verify-artifact-release.mjs` 门禁防止原图泄漏。
- **个人本地构建（`npm run build:local`）**：在本机已准备离线 OCR 资源与个人素材的前提下，可生成包含本地素材的个人便携版：

```bash
cd apps/web

# 首次准备离线 Tesseract OCR 语言包与核心文件
npm run prepare:ocr:download

# 构建公开版前端产物
npm run build

# 构建个人本地版前端产物（需本机具备完整离线资源与审计素材）
npm run build:local
```

## 安全与合规声明

1. **零内存读取 / 零注入**：本工具仅通过 Windows 标准窗口截图（`PrintWindow` / GDI）与前台输入 API 工作，不读取或修改游戏进程内存、不拦截网络数据包。
2. **人工在环控制**：当前页扫描仅在当前可见页内辅助点击格位并截图，**不具备自动翻页、自动改变锁定/装备或自动确认入库功能**；若原神以管理员权限运行导致快捷键或点击被系统隔离，请用户自行决定是否以相同权限运行本工具，程序绝不自动提权。
3. **美术与数据权利**：公开源码仓库不包含米哈游（miHoYo / Cognosphere）原始游戏美术资产；《原神》相关角色、圣遗物名称及游戏设定的知识产权归原权利人所有。
